# 📚 DSA Using Java

This repository contains basic implementations of **Data Structures and Algorithms** using **Java**. It’s designed for learning, practicing, and revising DSA concepts.

---

## 🛠️ Tech Stack

- Java (Core Java)
- CLI-based structure
- Object-Oriented Programming

---

## 📁 What's Inside

- Arrays  
- Linked Lists  
- Stacks  
- Queues  
- Trees  
- Sorting Algorithms  
- Searching Algorithms  
- Graphs (BFS, DFS)

---

## 🚀 Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/MTalhaofc/DSA_Using_Java.git
   ```
2. Open in your Java IDE (IntelliJ, Eclipse, VS Code)

3. Run any .java file to test a specific data structure or algorithm.
